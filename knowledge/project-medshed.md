
# Project: MedSched — Medicine Scheduling Application

## Overview
MedSched is a medicine scheduling application developed to help
users organize their medicine schedules.

## Technologies
- React
- TypeScript
- Vite
- Tailwind CSS

## Frontend
The application uses React and TypeScript to build its user interface.
Vite is used as the development and build tool.
Tailwind CSS is used for styling.

## Purpose
The project demonstrates frontend development skills and the
creation of a web application using a modern JavaScript framework.
