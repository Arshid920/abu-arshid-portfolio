
# Project: Vision-Enabled AI-Based Safety and Passenger Monitoring System

## Overview
This project uses computer vision and machine learning to monitor
passenger safety and identify potential risks in a boat environment.

## Technologies
- Python
- YOLOv8
- OpenCV
- Flask / FastAPI
- Random Forest
- SQLAlchemy
- Local database

## Main Features
- Detects boats and passengers using computer vision.
- Monitors passenger capacity.
- Uses a capacity limit of five passengers in the configured project.
- Classifies safety conditions into safe, caution, and unsafe categories.
- Uses camera input for monitoring.
- Stores application data using a local database.

## Technical Approach
- Python handles the application logic.
- YOLOv8 and OpenCV support object detection and image processing.
- A Random Forest model supports safety-condition classification.
- SQLAlchemy supports database operations.

## Project Purpose
The goal is to demonstrate how computer vision and machine learning
can assist with passenger monitoring and safety-risk awareness.
